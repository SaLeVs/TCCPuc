Inventário de Cena

Cada peça que dá para pôr num mapa do teatro, com o código para escrever na planta, o tamanho real e as regras do jogo que ela carrega: se tem colisor, se esconde você do monstro, se precisa de rede.

Gerado por Tools/TCC/Level Design/Exportar toolkit. Para colocar uma peça no Unity: Tools/TCC/Level Design/Toolkit (janela), busque o código e arraste para a cena.
